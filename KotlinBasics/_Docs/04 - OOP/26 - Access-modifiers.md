# Access modifiers

- public
- private
- internal
- protectected

## Top level símbols

### Public

A simbol can be used from anywhere.

**This is the default behaviour**.

### Private

A símbol can be used only in the same file.

### Internal

A símbol can only be accessed in the same module.

## Protected

It can't be used on top level siumbols.

## Class members

### Public

Default access. When no access modifier is specified, a member is assumed to be public. Any other class can access the method.

### Private

A member can only be accessed from the class it declares it.

### Internal



### Protected

It allows a member to be accessed from descendant classes.
